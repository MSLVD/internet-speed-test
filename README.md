# Замер скорости интернета

Скрипт `sobes.py` последовательно скачивает один и тот же ресурс 10 раз, дожидается полного ответа каждого запроса и выводит:

- время каждого запроса и среднее время;
- объем данных каждого запроса и общий объем;
- скорость каждой загрузки и среднюю скорость в `MB/s`.

Используется только стандартная библиотека Python, дополнительные пакеты не нужны.

## Запуск

Нужен Python 3.9 или новее.

```bash
python3 sobes.py https://speed.hetzner.de/100MB.bin
```

Количество запросов и таймаут можно изменить:

```bash
python3 sobes.py URL --requests 10 --timeout 30
```

Для честного измерения выбирайте большой файл на сервере, который находится далеко от локального кэша, и не запускайте параллельные загрузки. Скрипт хранит только текущий блок ответа, поэтому файл целиком в память не загружается.
